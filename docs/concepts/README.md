# Lia Studio — UI Concepts

These files are **visual direction references**, not pixel-perfect implementation specifications.

## Concepts

1. [`01-home-lia-studio-concept.svg`](./01-home-lia-studio-concept.svg)
   - Home / launcher.
   - Create Project, Open Project and Skills.
   - No active project pipeline.

2. [`02-project-workspace-lia-studio-concept.svg`](./02-project-workspace-lia-studio-concept.svg)
   - Open game project.
   - Central pipeline: Preparation → MVP Playable → Production → Finalization.
   - Left project navigation does **not** duplicate the pipeline.
   - Left and right panels are collapsible.
   - Right side contains Lia Copilot.

3. [`03-skills-workspace-lia-studio-concept.svg`](./03-skills-workspace-lia-studio-concept.svg)
   - Skills library and editor.
   - Skills are reusable knowledge, not game projects.
   - Lia acts as a contextual Skill Copilot.

## Relationship to generated visual concepts

The original generated image concepts remain the visual inspiration for these boards. The SVG files are committed because they are lightweight, versionable, inspectable and can be referenced by agents and documentation without requiring binary-image support.

The SVGs intentionally capture the **approved information architecture and visual relationships**, not every decorative detail of the original renders.
